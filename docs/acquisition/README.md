# EpsiFlow acquisition documents

This directory is the working source of truth for EpsiFlow acquisition strategy and collateral.

## Documents

- `epsiflow_overview.md` — product, customer, positioning, onboarding, and acquisition context.
- `email_campaign_v1.md` — first outbound campaign draft and operating guidance.
- `acquisition_rulebook.md` — reserved for the acquisition rulebook we will develop from campaign results and operating decisions.
- `instantly_integration.md` — historical Instantly delivery design, now superseded.
- `local_delivery.md` — current Instantly-source, Supabase-state, Yandex-delivery setup and rollout procedure.

## Working convention

Keep strategy, messaging, experiments, and sales guidance here as Markdown. Application code and executable campaign configuration remain in `src/` and `scripts/`.
